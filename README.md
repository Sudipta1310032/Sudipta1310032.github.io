# Sudipta Paul - GitHub Pages website

This folder contains a complete static website. It has no publications section and uses no background images.

## Publish

1. Copy `index.html`, `style.css`, and `Sudipta_Paul_CV.pdf` to the root of your `Sudipta1310032.github.io` repository.
2. Commit and push the files to the `main` branch.
3. In GitHub, open **Settings > Pages** and select **Deploy from a branch**, `main`, and `/ (root)`.

The site will be available at `https://Sudipta1310032.github.io/` after GitHub finishes deploying it.
